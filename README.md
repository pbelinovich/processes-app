# Процессы

Нативное приложение для меню-бара macOS 13+. AppKit, без сторонних зависимостей и без иконки в Dock.

## Сборка и запуск

Нужны Command Line Tools от Apple (`xcode-select --install`) и Swift 6+.

```sh
./scripts/build-app.sh
open dist/Processes.app
```

Готовое приложение можно перенести в `/Applications`. Локальная сборка подписывается ad hoc; для распространения другим пользователям потребуются Developer ID и нотариализация Apple.

## Использование

Нажмите на иконку пульса в меню-баре. По умолчанию открыта вкладка «Агенты»:

- Сверху оранжевым выделено то, что осталось после завершённых или неактивных сессий. «Остановить все» показывает одно подтверждение со списком процессов и проектов.
- Ниже — живые сессии Codex, Claude, Kimi и Cursor: проект, длительность и запущенные задачи. MCP живых сессий свёрнуты в счётчик «MCP N» справа в заголовке; подсказка перечисляет их имена. Сессии только с MCP или без задач занимают одну строку. Сессии с серверами и браузерами показаны первыми. Зелёная точка означает активную сессию, серая — неактивную (рядом указана длительность неактивности).
- «Прочие серверы (не от агентов)» свёрнуты внизу; нажмите на заголовок, чтобы раскрыть их.
- Вкладка «Все процессы» показывает компактный список всех доступных процессов по убыванию памяти RSS.

Поиск в обеих вкладках работает по имени, порту, пути проекта, команде и PID. Нажмите на порт, чтобы открыть `http://localhost:<порт>` в браузере по умолчанию. Нажатие на заголовок сессии открывает все её задачи, включая MCP. Поиск также раскрывает совпавшие MCP отдельными строками. Нажатие на строку процесса открывает подробности: PID, PPID, рабочую папку, полную команду и дерево задач. Команду можно скопировать.

Наведите курсор на процесс и нажмите «Остановить»: приложение завершает представленное дерево задач, сначала обычным сигналом, затем принудительно, если задачи не ответили. Итог показан в нижней строке; ошибки доступны в её подсказке. Несохранённые данные останавливаемых процессов могут быть потеряны. Завершать можно свои процессы, кроме PID 1 и самого приложения; системные ограничения macOS продолжают действовать. Перед сигналом проверяются PID, владелец и время запуска.

Число рядом с иконкой меню-бара показывает количество оставшихся задач. Снимок обновляется каждые 15 секунд в фоне, а при открытом окне — каждые 3 секунды. Кнопка со стрелкой обновляет список сразу. «Выйти» закрывает приложение.

Память RSS показана в МБ (1 МБ = 1024² байт), включая общие страницы. Это память отдельного процесса, а не сумма всего дерева и не показатель Memory из Activity Monitor. Прочерк означает, что macOS не предоставила данные. Порты определяются встроенным `lsof`; без доступа к сокетам сервер может отсутствовать в списке. Атрибуция зависит от доступных macOS данных и меток агента; неизвестные серверы остаются в отдельной секции.

## Проверка

```sh
swift build --build-system native
./scripts/test.sh
```

Проверки используют только собственные дочерние `sleep` и синтетические UI-фикстуры. Окна не показываются, фокус не меняется. PNG светлой и тёмной тем и состояний интерфейса сохраняются в `/tmp/processes-ui-02`; дополнительно создаётся `real-agents.png` из текущего снимка машины (только чтение), путь можно задать переменной `PROCESSES_SCREENSHOT_DIR`. Фикстуры компилируются только с `-D PROCESS_UI_CHECKS` и не входят в рабочее приложение.
