# Процессы

Нативное приложение для меню-бара macOS 13+. AppKit, без сторонних зависимостей и без иконки в Dock.

## Сборка и запуск

Нужны Command Line Tools от Apple (`xcode-select --install`) и Swift 6+.

```sh
./scripts/build-app.sh
open dist/Processes.app
```

Готовое приложение можно перенести в `/Applications`. Локальная сборка подписывается ad hoc; для распространения другим пользователям потребуются Developer ID и нотариализация Apple.

## Использование

- Нажмите на иконку пульса в меню-баре.
- Найдите процесс по имени, PID или пользователю.
- По умолчанию показаны свои процессы с сортировкой по памяти. «TCP-серверы» показывает процессы с доступными TCP LISTEN-сокетами, «Все» — весь доступный список. Сортировка: память, имя или сначала новые.
- В строке показаны RSS в МБ (1 МБ = 1024² байт), PID, PPID, время работы, TCP-порты и команда. RSS — резидентная память отдельного процесса, включая общие страницы; это не показатель Memory из Activity Monitor и не сумма памяти приложения со всеми дочерними процессами. Прочерк означает, что macOS не предоставила данные.
- Двойной клик открывает владельца, рабочую папку и полную команду с возможностью выделить текст или скопировать команду. Поиск также работает по команде, рабочей папке и порту. Переменные окружения приложение не читает и данные на диск не сохраняет.
- Список обновляется и при наведённом курсоре. После отправки сигнала выполняются немедленное обновление и повторные проверки через 250 мс и 1 с. Действия открытого меню привязаны к выбранному процессу независимо от обновлений списка. Порты определяются встроенным `lsof`; без доступа к сокетам процесс может отсутствовать во вкладке серверов.
- Наведите курсор на строку и нажмите «Завершить», затем выберите обычное или принудительное завершение.
- Обычное завершение отправляет SIGTERM: процесс может обработать или проигнорировать сигнал. Принудительное отправляет SIGKILL после подтверждения и может привести к потере несохранённых данных.
- Кнопка «Выйти» закрывает приложение.

Список обновляется каждые 3 секунды, только пока открыт попап. Процессы, сведения о которых разрешает читать macOS, отображаются для всех пользователей. Завершать можно свои процессы, кроме PID 1 и самого приложения; системные ограничения macOS продолжают действовать. Перед отправкой сигнала проверяются PID, владелец и время запуска, чтобы обнаружить устаревшую запись.

## Проверка

```sh
./scripts/test.sh
```

Тесты без XCTest проверяют получение списка, защиту собственного процесса, отклонение устаревшей записи, SIGTERM и SIGKILL на отдельных дочерних процессах `sleep`.
