# Процессы

Нативное приложение для меню-бара macOS 13+. AppKit, без сторонних зависимостей и без иконки в Dock.

## Сборка и запуск

Нужны Command Line Tools от Apple (`xcode-select --install`) и Swift 6+.

```sh
./scripts/build-app.sh
open dist/Processes.app
```

Готовое приложение можно перенести в `/Applications`. Локальная сборка подписывается ad hoc; для распространения другим пользователям потребуются Developer ID и нотариализация Apple.

Чтобы включить запуск при входе, сначала разместите приложение в постоянной папке, затем выполните:

```sh
/Applications/Processes.app/Contents/MacOS/ProcessesMenu --enable-login-item
```

Автозагрузка регистрируется через `SMAppService` macOS. Отключить её можно в «Системные настройки → Основные → Объекты входа». Если macOS требует подтверждения, команда сообщит об этом.

## Использование

Нажмите на иконку пульса в меню-баре. Повторное нажатие закрывает окно; также оно закрывается по Escape, клику снаружи или переходу в другое приложение. По умолчанию открыта вкладка «Агенты»:

- Сверху оранжевым выделено то, что осталось после завершённых или неактивных сессий. «Остановить все» показывает одно подтверждение со списком процессов и проектов.
- Ниже — живые сессии Codex, Claude, Kimi и Cursor: проект, длительность и запущенные задачи. Справа в заголовке показан счётчик «MCP N»; подсказка перечисляет имена MCP. Шеврон показывает, раскрыта ли сессия. Сессии с серверами или браузерами и оставшиеся сессии раскрыты сразу; сессии только с MCP свёрнуты в одну строку, у сессий без задач шеврона нет. Сессии с серверами и браузерами показаны первыми. Зелёная точка означает активную сессию, серая — неактивную (рядом указана длительность неактивности) или задачи самого приложения Codex: например, MCP, которые его фоновый демон держит для всех тредов. Такие задачи живут вместе с демоном и не считаются оставшимися.
- «Прочие серверы (N)» свёрнуты внизу; нажмите на заголовок, чтобы раскрыть их.
- Вкладка «Все процессы» показывает компактный список всех доступных процессов по убыванию памяти RSS.

Поиск в обеих вкладках работает по имени, порту, пути проекта, команде и PID. Нажмите на порт, чтобы открыть `http://localhost:<порт>` в браузере по умолчанию. Нажатие на заголовок сворачивает или раскрывает задачи сессии, включая приглушённые MCP в конце списка. Выбор сохраняется при обновлении. Поиск сразу раскрывает совпавшие процессы. Нажатие на процесс показывает подробности прямо под его строкой: папку, команду, PID / родителя, порты и число задач дерева. Команда выделяется и переносится; после трёх строк доступно «Показать всё». Здесь же можно открыть порт, скопировать команду, показать папку в Finder или остановить процесс. Одновременно раскрыты подробности одного процесса.

При наведении на процесс память заменяется кнопкой «Остановить»: приложение завершает представленное дерево задач, сначала обычным сигналом, затем принудительно, если задачи не ответили. Итог показан в нижней строке; ошибки доступны в её подсказке. Несохранённые данные останавливаемых процессов могут быть потеряны. Завершать можно свои процессы, кроме PID 1 и самого приложения; системные ограничения macOS продолжают действовать. Перед сигналом проверяются PID, владелец и время запуска.

Число рядом с иконкой меню-бара показывает количество оставшихся задач; пока они есть, иконка и число оранжевые, иначе иконка белая или чёрная под тему меню-бара. Снимок обновляется каждые 15 секунд в фоне, а при открытом окне — каждые 3 секунды. Высота окна подстраивается под содержимое от 368 до 688 pt. Кнопка со стрелкой обновляет список сразу. «Выйти» закрывает приложение.

Память RSS показана в МБ (1 МБ = 1024² байт), включая общие страницы. Это память отдельного процесса, а не сумма всего дерева и не показатель Memory из Activity Monitor. Прочерк означает, что macOS не предоставила данные. Порты определяются встроенным `lsof`; без доступа к сокетам сервер может отсутствовать в списке. Атрибуция зависит от доступных macOS данных и меток агента; неизвестные серверы остаются в отдельной секции.

В основном окне в нижнем сером блоке, под статистикой процессов и рядом с кнопкой «Выйти», расположена неброская строка системных показателей: CPU, занятая / установленная память, свободное место и время без перезагрузки. Она видна в обеих вкладках, обновляется каждые 3 секунды при открытом окне и кнопкой обновления. Наведите на показатель, чтобы увидеть пояснение; версия macOS и полные значения доступны в подсказке строки.

## Работа с закрытой крышкой

Правый клик (или Control-клик) по иконке открывает нативное меню с пунктом «Не усыплять Mac», блоком системной информации и отдельным пунктом «Выйти» внизу. Галочка показывает текущее состояние macOS; выбор пункта включает или выключает ту же настройку, что и галочка в основном окне. Перед открытием меню состояние перепроверяется. Ошибка переключения показывается системным диалогом. Под разделителем показаны версия macOS, загрузка CPU (0–100 % по всем ядрам, короткий замер при открытии), занятая физическая память без файлового кэша, свободное место на томе домашней папки и время без перезагрузки. Значения обновляются при каждом открытии меню; недоступные данные показаны прочерком.

Когда сон отключён, в правом нижнем углу иконки пульса в меню-баре появляется синяя точка без изменения ширины иконки. Оранжевый цвет пульса и счётчик оставшихся задач продолжают работать независимо. Индикатор показывает проверенное состояние системы, обновляется в фоне каждые 15 секунд и сразу после переключения галочки. Если состояние прочитать не удалось, точка скрывается, а подсказка сообщает, что состояние сна неизвестно.

Внизу окна есть галочка «Не усыплять Mac при закрытой крышке». Она управляет системной настройкой `pmset disablesleep`: агенты могут продолжать работу без внешнего монитора. При первом изменении macOS один раз запрашивает пароль администратора: приложение устанавливает правило `/private/etc/sudoers.d/processes_sleep_<UID>`, разрешающее текущему пользователю только две точные команды `pmset -a disablesleep 0` и `pmset -a disablesleep 1` без пароля. Следующие переключения, включая после перезапуска, выполняются без запроса пароля. Это разрешение доступно любому процессу текущего пользователя; другие команды административных прав не получают. Чтобы удалить разрешение, выполните `sudo rm /private/etc/sudoers.d/processes_sleep_$(id -u)`; сама настройка сна при удалении правила не меняется. Галочка показывает прочитанное состояние системы, которое перепроверяется при открытии окна и обновлении списка; отмена запроса или ошибка не отображаются как успешное изменение.

Настройка действует от сети и батареи и сохраняется после выхода из приложения. Чтобы вернуть обычный сон, снимите галочку (или выполните `sudo pmset -a disablesleep 0`). Для долгой работы подключите питание; не убирайте работающий ноутбук в сумку. Фактическую работу при закрытой крышке нужно проверить на своей модели Mac и версии macOS.

## Проверка

```sh
swift build --build-system native
./scripts/test.sh
```

Проверки используют только собственные дочерние `sleep` и синтетические UI-фикстуры. Окна не показываются, фокус не меняется. PNG светлой и тёмной тем и состояний интерфейса сохраняются в `/tmp/processes-ui-04`; дополнительно создаётся `real-dark.png` из текущего снимка машины (только чтение), путь можно задать переменной `PROCESSES_SCREENSHOT_DIR`. `grid-check.png` накладывает линии сетки 12/28/42/62/trailing−12. Фикстуры компилируются только с `-D PROCESS_UI_CHECKS` и не входят в рабочее приложение.
